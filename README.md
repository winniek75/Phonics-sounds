# フォニックスサウンド（Phonics Sounds）

英語の単語を「きいて」、ターゲットの音があるかを YES / NO で答える、子ども向けの音の聞き分け練習です。
素の HTML 1ファイル（`index.html`）で動きます。

## あそびかた

1. スタート画面で練習する文字（音）をえらぶ（複数可）
2. モードをえらぶ
   - **れんしゅう**：時間制限なし。5問 / 10問で終わる。回答ごとに解説を見て「つぎへ」で進む
   - **タイムアタック**：30秒。解説の表示中は時計が止まる
3. 最初の2問は「おためし」（採点・記録なし）。「もういちど！」での再挑戦では出ない
4. 回答後に「sun → さいしょが /s/」のように単語・音の位置を表示

### 判定基準（画面に表示される文）

判定は単語データの `hasTarget` で行い、画面の文はデータから自動で決まります。

- YES の単語がすべてその文字で始まるレッスン → 「さいしょの おとが /s/ かな？」
  （現在：s t p n h r m d g l f b）
- それ以外 → 「ことばの どこかに /a/ の おとが あるかな？」
  （現在：a i e o u ck）

レッスンに `rule: 'first'` / `rule: 'any'` を書けば手動で指定できます。

## URL パラメータ（ポータルからの直接指定）

| パラメータ | 内容 | 例 |
|---|---|---|
| `letters` | 練習する文字。カンマ区切り（`letter` でも可） | `letters=s,a` |
| `mode` | `practice`（時間なし） / `time`（30秒タイムアタック） | `mode=practice` |
| `count` | れんしゅうモードの問題数（3〜20。`mode` 省略時は practice になる） | `count=10` |
| `warmup` | `0` でおためし2問を出さない | `warmup=0` |

例：`index.html?letters=s,a&mode=practice&count=10`

- 指定した内容がえらばれた状態でスタート画面が開き、「あそぶ！」を1回おすと始まります
  （ブラウザの音声自動再生の制限のため、自動スタートはしません）。
- 複数の文字を指定すると、問題数を文字ごとに均等に分け、文字ごとにまとめて出題します。
- 単語データがまだ無い文字（G4〜G7）は無視され、「じゅんびちゅう」と表示されます。
- パラメータが無ければ通常のスタート画面です。

## 単語データ

`index.html` 内の `LESSONS` を編集します（`lessons.js` は現在読み込まれていません）。

```js
"s": { words: [
  { word: "sun", hasTarget: true  },
  { word: "cat", hasTarget: false },
]},
```

- `hasTarget: true` → YES が正解 / `false` → NO が正解
- `sound: 'ながい /oo/'` を単語に書くと、解説の音の表記に使われます
  （oo・th のように 1つのボタンで 2種類の音をあつかう文字用。説明文は `SOUND_NOTES`）
- 絵は `images/words/{単語}.png` があればそれを、無ければ `WORD_EMOJI` の絵文字を表示

## 音声

Google 翻訳 TTS（要インターネット）。再生できない場合はブラウザ内蔵の音声合成に切り替えます。
